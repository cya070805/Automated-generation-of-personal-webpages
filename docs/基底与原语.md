# 基底、原语与配方

对应方案 02 章。三层各管一件事：

| 层 | 是什么 | 决定什么 | 数量 |
| --- | --- | --- | --- |
| 基底 Base | 一套设计令牌 + 排版节奏 | 整页气质：字体、色板、圆角、疏密 | 6 |
| 原语 Primitive | 一个动效或材质能力 | 局部质感 | 12 |
| 配方 Recipe | 一个槽位的讲法 | 这一屏的结构与节奏 | 15（种子） |

代码位置：

```
src/lib/templates/bases.ts      六套基底（纯令牌）
src/lib/templates/recipes.ts    配方库 + 默认组合
src/components/primitives/      十二个原语
src/components/render/          渲染层：槽位组件 + SiteView
```

## 六套基底

| id | 名字 | 气质 | 适合 |
| --- | --- | --- | --- |
| `paper` | Paper | 白纸黑字、字号阶梯、细线分层 | 通用 |
| `terminal` | Terminal | 等宽、暗底、扫描线 | 计算机 / 算法 / 后端 |
| `editorial` | Editorial | 衬线大字、窄栏、引文块 | 文字多、人文社科 |
| `gallery` | Gallery | 大图少字、横向画廊 | 设计 / 摄影 / 建筑 |
| `studio` | Studio | 深色底、等距网格、紫色强调 | 前端 / 创意技术 |
| `bento` | Bento | 大小不一的格子、中等圆角 | 产品 / 工程，模块多 |

基底**只给令牌**，不给版式。同一个「经历」槽位，Paper 用编号条目、Editorial 用时间线、
Bento 用卡片——那是配方的差别，换基底会自动挑该基底的默认讲法。

## 十二个原语

| id | 名字 | 组合出什么 | 需要 JS |
| --- | --- | --- | --- |
| `gradient-grid` | 渐变 / 网格底 | 首屏背景、分区底色 | 否 |
| `grain` | 噪点 / 颗粒 | 胶片感、纸质感 | 否 |
| `mask` | 遮罩 / 裁切 | 异形图、文字镂空 | 否 |
| `sticker` | 描边 / 贴纸 | 手绘感、标注感 | 否 |
| `glass` | 玻璃 / 模糊 | 卡片、导航条 | 否 |
| `scanline` | 扫描线 / 边框光效 | CRT 质感、科技卡片 | 否 |
| `meter` | 微型图表 | 技能刻度、数字胶囊 | 否 |
| `particles` | 粒子 / 流体 | 背景、加载态 | 否 |
| `typewriter` | 打字机 / 文字拆分 | 标题动画 | 是 |
| `magnetic` | 光标跟随 / 磁吸 | 按钮与卡片的反馈 | 是 |
| `tilt` | 倾斜 / 视差 | 作品卡 | 是 |
| `scroll` | 滚动驱动 | 长页叙事、时间线 | 是 |

前八个是纯 CSS / SVG，服务端渲染，导出 PDF 不会抖；
后四个是客户端岛，全部遵守 `prefers-reduced-motion`，关掉动效后内容一个字不少。

## 配方是数据

```json
{
  "id": "projects.strip",
  "name": "横向画廊",
  "slot": "projects",
  "layout": "strip",
  "compatible": ["gallery", "studio"],
  "primitives": ["scroll"],
  "motionCost": "medium"
}
```

页面里只存引用：`pages.recipeMap = { hero: "hero.bento", projects: "projects.strip" }`。
没存、存了不存在的、或者跟当前基底不兼容，都会回落到该基底的默认讲法
（`resolveRecipeMap`），所以换基底永远不会破版。

## 怎么加

**加一套基底**：在 `bases.ts` 照抄一份改令牌，`status: "ready"`，再在
`DEFAULT_RECIPE_MAP` 里给它挑六条默认配方。选择器读 `READY_BASES`，会自动出现。

**加一条原语**：`primitives/` 里写组件，`index.ts` 加一条 meta。

**加一条配方**：`recipes.ts` 加条目，`render/slots.tsx` 写对应 `layout`，
`site-view.tsx` 的 `LAYOUTS` 里接上。

## 约束

- 一套基底只用一个强调色
- 基底之间要像「不同家族」，不是「不同皮肤」：字号阶梯、行宽、疏密都要真的不同
- 每个槽位必须能空着渲染：没有经历、没有项目、没有邮箱都不能塌
- 正文行宽 46–60 个中文字符，超过就不是给人读的
