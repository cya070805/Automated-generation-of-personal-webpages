# 部署到阿里云服务器

面向「第一次弄服务器」的人。目标：用公网 IP + 3000 端口把站点跑起来，10 分钟内能访问。

后面有域名再照着最后一节加，不着急。

---

## 0. 先认清三件事

### 你的系统是什么

连上服务器后执行：

```bash
cat /etc/os-release
```

看输出里的 `ID=` 或 `PRETTY_NAME=`：

| 输出里出现 | 系统 | 装东西的命令 |
| --- | --- | --- |
| `Ubuntu` / `Debian` | Ubuntu、Debian | `apt` |
| `alinux3` / `Alibaba Cloud Linux` | 阿里云 Linux | `dnf` |
| `CentOS` / `Rocky` | CentOS 系 | `dnf` |

顺手看内存：

```bash
free -h
```

`Mem:` 那一行是总量。2G 够用（够构建，不用加 swap 也能过，但保险起见第 4 节给了加 swap 的命令）。

### 服务器上的东西都在哪

- `/opt/ludao` —— 代码放这里
- `/opt/ludao-data/app.db` —— 数据库（SQLite 一个文件，备份就是拷这个文件）

### 域名 vs IP

- **IP**：`47.xx.xx.xx`，服务器自带的公网地址，现在就能用，不用买、不用备案。缺点：难记，重建实例可能变。
- **域名**：`ludao.com` 这种好记的地址，指向你的 IP。要花钱买（几十块一年）。
- **备案**：国内机房的域名必须先备案才能用 80/443 访问，个人备案一般 1～3 周。

**结论：先用 `http://公网IP:3000` 访问，不花钱也不用备案。**

## 1. 连上服务器

阿里云控制台 → 云服务器 / 轻量应用服务器 → 找到实例 → **远程连接**（Workbench）。

- 用户名：`root`（有些镜像默认是 `ecs-user`）
- 密码：买的时候设置的，忘了可以在控制台「重置密码」

不用装 Xshell / PuTTY，控制台自带的终端够用。

---

## 2. 放行端口

站点跑在 3000 端口，云厂商的防火墙默认只开 22/80/443。

- **轻量应用服务器**：实例详情 → 防火墙 → 添加规则 → `TCP` / `3000` / 所有来源
- **ECS**：实例 → 安全组 → 配置规则 → 入方向 → 添加 `TCP 3000` / 源 `0.0.0.0/0`

系统自带的防火墙也放行一下（二选一，缺哪个补哪个）：

```bash
# Ubuntu / Debian
ufw allow 3000 || true

# 阿里云 Linux / CentOS（firewalld 没开会报错，忽略即可）
firewall-cmd --add-port=3000/tcp --permanent && firewall-cmd --reload || true
```

## 3. 装 Node 22 和 git

**Ubuntu / Debian：**

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt install -y nodejs git
```

**阿里云 Linux / CentOS / Rocky：**

```bash
curl -fsSL https://rpm.nodesource.com/setup_22.x | bash -
dnf install -y nodejs git
```

确认：

```bash
node -v      # 期望 v22.x
npm -v       # 期望 10.x
```

国内服务器下载 npm 包慢，先换成镜像源（只影响这台机器）：

```bash
npm config set registry https://registry.npmmirror.com
```

## 4. 拿代码

```bash
mkdir -p /opt && cd /opt
git clone https://github.com/cya070805/Automated-generation-of-personal-webpages.git ludao
cd ludao
```

> 国内访问 GitHub 慢或超时的话，在你本机打包再传上去：
>
> ```bash
> # 本机（Windows 的 Git Bash 里执行）
> cd "D:/杂/个人网站生成" && git archive -o ludao.tar.gz HEAD
> ```
>
> 然后用 WinSCP / 控制台的文件上传把 `ludao.tar.gz` 传到服务器 `/opt`，再：
>
> ```bash
> mkdir -p /opt/ludao && tar -xzf /opt/ludao.tar.gz -C /opt/ludao
> ```

## 5. 配环境变量

```bash
mkdir -p /opt/ludao-data
cat > /opt/ludao/.env <<'EOF'
DATABASE_URL="file:/opt/ludao-data/app.db"
EOF
```

**只写这一行就够了。** 不要往这里放 `LLM_API_KEY`——站点没有登录，任何打开页面的人都会用掉你的额度。自己的 Key 在网页右上角「模型设置」里填，只存在你自己的浏览器。

---

## 6. 装依赖 + 建库

```bash
cd /opt/ludao
npm ci                     # 约 2 分钟，400MB 左右
npx prisma migrate deploy  # 建表
npm run db:seed            # 可选：建一个示例主页
```

`.env` 里的数据库是绝对路径，跑起来以后内容都在 `/opt/ludao-data/app.db`，重新部署代码不会丢。

---

## 7. 构建

```bash
npm run build
```

2G 内存一般能过（峰值 1～1.5G）。如果卡住不动、或者看到 `Killed` / `JavaScript heap out of memory`，加 2G swap 再重跑：

```bash
fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
free -h          # Swap 那行应该变成 2.0Gi
npm run build
```

---

## 8. 让它一直跑着

直接 `npm start` 也行，但 ssh 一断就停。用 pm2：

```bash
npm i -g pm2
cd /opt/ludao
pm2 start npm --name ludao -- start
pm2 save               # 记住当前进程
pm2 startup            # 开机自启（按它输出的那行命令再执行一次）
```

常用：

```bash
pm2 status             # 在不在跑
pm2 logs ludao         # 看日志（Ctrl+C 退出）
pm2 restart ludao      # 改完代码重启
```

现在浏览器打开 `http://你的公网IP:3000` 就能用了。

---

## 9. 以后改了代码怎么更新

```bash
cd /opt/ludao && git pull && npm ci && npx prisma migrate deploy && npm run build && pm2 restart ludao
```

一行复制粘贴即可。数据库在 `/opt/ludao-data`，不会被覆盖。

## 10. 想要域名的时候（可选）

1. 阿里云「域名」里买一个 → 实名认证
2. 控制台「备案」提交个人备案（需要身份证、手机号核验，约 1～3 周）
3. 备案通过后，在「云解析 DNS」加一条 `A` 记录，主机记录 `@`，值填服务器公网 IP
4. 用 nginx 把 80 端口转到 3000：

```bash
apt install -y nginx        # 或 dnf install -y nginx
cat > /etc/nginx/conf.d/ludao.conf <<'EOF'
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_buffering off;          # 流式输出要关掉缓冲
    }
}
EOF
nginx -t && systemctl reload nginx
```

`proxy_buffering off;` 别删——AI 回答是流式的，开着缓冲会等全部生成完才一次性吐出来。

https 更省事的做法：在阿里云申请免费 SSL 证书，或者用 certbot 自动签。

## 11. 出问题看这里

| 现象 | 原因 / 处理 |
| --- | --- |
| 浏览器打不开 IP:3000 | 九成是安全组/防火墙没放行 3000。先在服务器上 `curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:3000/api/health`，返回 200 就说明是网络层的事 |
| 页面能开，但一点「生成」就报错 | 没填 Key。右上角「模型设置」里填一个 |
| `npm run build` 卡住或 Killed | 内存不够，照第 7 节加 swap |
| `npm ci` 慢到超时 | 没换源，执行第 3 节最后那行 `npm config set registry` |
| prisma 报 engine 下载失败 | `export PRISMA_ENGINES_MIRROR=https://registry.npmmirror.com/-/binary/prisma` 再重试 |
| 重启服务器后站点没了 | 没执行 `pm2 save` / `pm2 startup` |
| 上传简历报错 500 | 看 `pm2 logs ludao`，多半是 `/opt/ludao-data` 权限或磁盘满 |

## 12. 这个站的性质，放公网前想清楚

- **没有账号系统**：任何人打开你的 IP 都能建主页，身份凭证就是一条随机编辑链接。不想被陌生人用，就别把地址发出去；或者加一层 nginx 的 `auth_basic`。
- **AI 调用**：用访问者自己浏览器里的 Key，服务器不存 Key、不写日志。
- **备份**：`cp /opt/ludao-data/app.db /opt/ludao-data/app.db.$(date +%F)`，隔几天拷一份到本机。
- **服务器到期**：免费试用到期的前一天备份 `app.db`，换机器时把代码重新 clone、把 `app.db` 拷回 `/opt/ludao-data` 就行。
