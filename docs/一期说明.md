# 一期交付说明

一期只做三件事：**应用骨架、十张表、模型接入**。目标是让后续二期（内容闭环）、
三期（呈现闭环）、四期（画布与导出）有地方长——而不是先做界面。

## 做了什么

### 1. 应用骨架

- Next.js 15（App Router）+ TypeScript + Tailwind CSS v4。
- 设计令牌落在 CSS 变量里（纸色、墨色、藏蓝、青、暖棕），换风格即换一组变量。
- 页面：`/` 总览、`/settings` 模型接入、`/workspace` 数据层自检。
- 不引入账号体系：身份就是 `projects.edit_token`。

### 2. 十张表

严格按文档 2.3 建表，**没有 users，也没有 keys**：

| 表 | 作用 |
| --- | --- |
| `projects` | 匿名项目，编辑链接的钥匙 |
| `resumes` | 一份简历的容器 |
| `resume_blocks` | 内容块，带 `source_quote` 与 `confidence` |
| `chat_sessions` | 一次追问会话（`gap_list`） |
| `messages` | 对话记录（`asked_field`） |
| `pages` | 呈现层（`theme` / `layout`），与内容分离 |
| `page_versions` | 版本与回滚 |
| `assets` | 头像与作品图 |
| `shares` | 分享页（slug / 访问密码 / noindex） |
| `exports` | 静态包 / 动态包记录 |

Python 侧的文档生成脚本和 PDF 原件放在 `docs/`，不参与构建。

### 3. 模型接入

- **预设**：DeepSeek、通义千问、智谱 GLM、Kimi、OpenAI，各自带 baseURL 与推荐模型。
- **自定义**：任何 OpenAI 兼容服务（本地 Ollama、vLLM、公司网关）。
- **Key 存哪**：只存浏览器 `localStorage`（键名 `lvdao.settings.v1`），不上传、不入库。
- **怎么转发**：`POST /api/llm/chat` 同源转发，Key 从 `x-llm-key` 请求头读取，
  只在上游请求头里过一遍；转发层无状态、不写日志、不落盘。
- **流式**：上游 SSE 原样直通，浏览器端逐段解析。
- **错误映射**：401/403 → `AUTH`；429 → 退避重试一次；60s → `TIMEOUT`；
  连续失败会建议切模板模式。
- **地址校验**：只允许 https 或本机 http；内网段默认拦截（`ALLOW_PRIVATE_LLM=1` 放开）。
- **没有 Key**：设置页有模板模式开关，整个流程不依赖模型也能走。

## 怎么验收

```bash
npm install
cp .env.example .env
npm run db:push
npm run dev
```

1. 打开 `/workspace`，十张表的计数应当能从数据库读出来（`GET /api/health` 返回 `ok: true`）。
2. 点「建一个空项目」，会拿到一条带随机密钥的编辑链接，`projects/resumes/pages` 各加一。
3. 打开 `/settings`，选一家服务，填入你自己的 Key，点「测试连接」：
   - 正确 Key → 绿色「连接成功 · xx ms」
   - 错误 Key → 红色「Key 无效或额度不足（401 / 403）」+ 上游信息
4. 不填 Key 也能用：把模板模式打开，导航栏状态会变成「模板模式」。

## 已知边界（一期故意不做）

- 没有登录与找回：编辑链接丢了就找不回。
- 没有内容编辑器：`/edit/[token]` 路由在二期随「内容闭环」一起做。
- 没有发布与导出：三、四期做。
- 没有 Dockerfile：四期随部署包一起给。
- 数据库本地用 SQLite；换 Postgres 需要改 `datasource` 并重新生成迁移。
