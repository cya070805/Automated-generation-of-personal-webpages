# 模板

## 现在有什么

| id | 名字 | 一句话 | 适合 |
| --- | --- | --- | --- |
| `paper` | Paper | 白纸黑字，一页读完 | 通用。投什么岗位都不会出错，打印出来也好看 |
| `terminal` | Terminal | 深色终端，信息密度高 | 计算机、算法、后端 |

默认 `paper`。模板选择在 `/edit/{token}` 页底部，选完即时生效，预览在 `/preview/{token}`。

## 为什么只有两套

参考了 B 站上播放量高的个人主页成品，风格大致分九类（见 `docs/refs/参考风格观察.md`）。
其中真正适合「学生 / 实习生投简历」的只有下面五类，先做前两套：

1. Paper 极简
2. Terminal 深色
3. Editorial 杂志（备选）
4. Gallery 画廊（备选）
5. Studio 等距 3D（备选）

剩下四类（复古报纸、霓虹撞色、手绘、3D 拟物）不做：前两种在 30 秒筛选里是噪音，
手绘会显幼，3D 渲染和「简洁、可打印」冲突。

## 怎么加一套

三步，都不用动页面：

1. 在 `src/lib/templates/` 写一个组件，接收 `{ data: SiteData }`
2. 在 `registry.tsx` 的 `TEMPLATES` 里加一条，`status: "ready"`
3. 在 `TemplateView` 的 `switch` 里接上

选择器读的是 `READY_TEMPLATES`，所以新模板会自动出现在选择界面里。

`status: "planned"` 的条目只在代码里占位，界面上不出现——免得交付时让人看到没做完的东西。
要开一套备选：把 status 改成 `ready`，补上组件和 switch 分支即可。

## 模板拿到什么

模板只认 `SiteData`，不认数据库：

```ts
interface SiteData {
  name: string;
  headline: string;   // 目标岗位
  summary: string;
  email: string;
  city: string;
  sections: { kind; title; org; period; lines[] }[];
  skills: string[];   // 可能是词表，也可能是一句话
}
```

`buildSiteData()` 负责把内容块压成这个形状：

- 有 `versions` 就取 `chosen` 那版，没有就退回 `details`
- 按 经历 → 项目 → 教育 排序，同类保持录入顺序
- 跳过头像、备注、空块
- 只放行 `email` 和 `city`，**手机号永远不进模板**

## 约束

- 不加阴影、不加卡片堆叠，靠字号阶梯和细线分层
- 一套模板只用一个强调色
- 页面在 1280px 和 768px 都要能读，正文行宽不超过 60–65 个中文字符
- 结构上先内容后装饰：删掉所有 hover 效果，信息是否仍然清楚
